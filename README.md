# ESCC APOBEC Mutagenesis — Reproducibility Code

## Overview

This repository contains Python scripts supporting the manuscript:

**Genomic Correlates of APOBEC-Associated Mutagenesis in Esophageal Squamous Cell Carcinoma**

The study investigates APOBEC-associated mutagenesis in 552 esophageal squamous cell carcinoma (ESCC) tumors from eight countries.

The repository includes ten analysis scripts covering mutational signatures, PCA, SBS18 associations, geographic sensitivity analyses, regression diagnostics, and driver-gene associations.

## Installation

Python 3 is required. Install the recorded dependencies using:

    python -m pip install -r requirements.txt

## Required input datasets

Place the following files at their specified locations relative to the repository root:

1. results/signatures_fast/SBS96/Suggested_Solution/COSMIC_SBS96_Decomposed_Solution/Activities/COSMIC_SBS96_Activities.txt
2. results/APOBEC_PCA_with_country.csv
3. results/APOBEC_driver_merged.csv
4. results/driver_mutations_from_vcf.csv
5. input/ESCC/output/vcf_files/SNV/17_seqinfo.txt

These sample-level genomic datasets are excluded from the repository pending confirmation of redistribution permissions.

The scripts do not automatically download or reconstruct these input files.

## Running the analyses

Run these commands from the repository root after preparing the required input datasets.

### Mutational signature analyses

    python scripts/reviewer1_compositional_sensitivity.py
    python scripts/reviewer1_pca_sensitivity.py
    python scripts/reviewer1_sbs18_robustness.py

### Geographic analyses

    python scripts/reviewer2_country_model_test.py
    python scripts/reviewer2_country_model_exclude_uk.py
    python scripts/reviewer2_country_stratified_sbs18.py

### Regression diagnostics

    python scripts/reviewer2_regression_diagnostics.py

### Driver-gene analyses

    python scripts/reviewer_driver_analysis.py
    python scripts/reviewer_driver_background_adjusted.py

### ZNF750 mutation-context analysis

    python scripts/reviewer_znf750_apobec_context.py

The ZNF750 context analysis requires the file:

    results/revision_R1/tables/R1_ZNF750_mutation_details.csv

This file is generated by reviewer_driver_analysis.py, which must be run first.

## Outputs

Generated analysis files are written primarily to:

    results/revision_R1/

The UK-exclusion geographic sensitivity analysis writes its outputs to:

    results/revision_R1/geography_sensitivity/

## Reproducibility status

All ten scripts were successfully executed in the authors' local reproducibility directory with the required inputs.

Independent execution in a clean environment has not yet been verified.

This repository provides code for the specified statistical and sensitivity analyses, not a complete raw-sequencing-to-manuscript computational pipeline.

## Data availability
